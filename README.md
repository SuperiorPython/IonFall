# Ionfall

A top-down survival defense game built in Unity (2D), developed as a senior year scholarship project.

**🎮 Play the current build:** [ionfall.netlify.app](https://ionfall.netlify.app/)

> This is an early, in-progress build — placeholder art and debug UI are intentional at this stage. Visual polish is planned for a later development phase.

---

## About

Ionfall drops the player into control of a stationary defensive dome on a hostile alien planet. During the night, alien creatures attack from all directions while automated miners extract ions beneath the surface. During the day, the player spends collected ions on upgrades to prepare for the next wave — until, eventually, the corporation funding the operation abandons the mission entirely, leaving the player to survive alone for as long as they can.

**Core systems:**
- Day/night cycle driving the core gameplay loop
- Turret combat with a heat/overheat management mechanic
- Enemies that scale in number and difficulty each night
- Ion-based economy and a branching upgrade system (Turret / Dome / Mining)
- Limited-use repair cards as an emergency resource
- A "corporate shutdown" narrative event that removes progression and escalates difficulty indefinitely

## Running Locally

1. Clone this repo
2. Open the project folder in Unity Hub (2022.3.x or later recommended)
3. Open `Scenes/SampleScene`
4. Press Play
